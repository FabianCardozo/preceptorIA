# PreceptorIA

Aplicación web de preceptoría para escuelas secundarias.

## Funciones
- Pase de lista y tardanzas
- Gestión de estudiantes
- Libro de novedades
- Justificaciones
- Convivencia
- Notas a familias
- Configuración institucional
- Copias de seguridad

## Desarrollo local
```bash
npm install
npm run dev
```

## Compilación
```bash
npm run build
```

Proyecto construido con React, TypeScript y Vite. La persistencia actual utiliza almacenamiento local; la integración con Supabase se incorpora como backend compartido.
